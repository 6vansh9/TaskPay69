# TaskPay — Student Freelance Marketplace

## About
India's first student-centric freelance marketplace.
Built by a student, for students.
Live: https://taskpay69.vercel.app

## Tech Stack
- Next.js 14 (App Router)
- TypeScript + Tailwind CSS
- Supabase (Auth, DB, Storage, Realtime)
- Razorpay (Payments)
- Groq AI (TaskBot, Bio generation)
- Twilio (Phone verification)
- Resend (Email)
- Vercel (Deployment)

## Features
- Dual role: Client and Freelancer
- Job posting and bidding with Connects system
- Escrow-based payments (90/10 split)
- Real-time chat per contract
- Phone + .edu student verification badges
- AI TaskBot assistant
- AI dispute resolver
- Admin panel with financial dashboard
- Dark/light theme

## Setup
1. Clone the repo
2. Copy .env.local.example to .env.local
3. Fill in your API keys
4. Run: pnpm install
5. Run: pnpm dev
6. Open: http://localhost:3000
